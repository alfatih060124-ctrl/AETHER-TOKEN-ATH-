01 / Product Map

Four connected product layers.

AVAILABLE / EVOLVING

AETHER Wallet (AW)

The self-custody and Web3 access layer of AETHER. It is designed around user-controlled authorization and a unified interface for supported networks and services.

  • Create and import wallet workflows
  • Watch-only wallet monitoring
  • Assets, send and receive
  • Market, swap and DApp discovery interfaces
  • WalletConnect/Web3 connectivity where supported
  • Network/RPC and security tooling

Some integrations depend on network, provider, app version or external service availability.

GATED RELEASE MODEL

ATH Token & Mining

The ATH digital-asset layer combines token utility with mining/reward, referral, booster and vesting concepts. Testnet validation and production/mainnet release are treated as separate stages.

  • Reward calculation and claim flows
  • Vesting visibility and transparent state
  • Referral and booster mechanics where enabled
  • On-chain records/events where implemented

No displayed reward, simulation or roadmap item should be interpreted as a guaranteed financial return.

CONTROLLED AUTOMATION

AETHER AUTOTRADE

The automation and market-execution layer. It is designed for market scanning, net-edge evaluation, multi-venue logic, risk controls and execution analytics.

  • SHADOW/simulator workflows for validation
  • Market and execution telemetry
  • Risk-aware position sizing
  • Multi-DEX/venue architecture where supported
  • Explicit execution gates

LIVE execution must never be inferred from the existence of the interface. Runtime status and release gates are authoritative. Automation does not guarantee profit.

ASSISTANCE LAYER

AETHER AI

The ecosystem assistance layer for product education, navigation, support and safer Web3 guidance. It should answer in the user's language and distinguish live features from gated or dependent capabilities.

  • Product explanations and navigation
  • Multilingual assistance
  • Security reminders
  • Official-link routing
  • Feature-status aware guidance

AETHER AI must never request seed phrases, private keys, passwords, OTPs or recovery secrets.

02 / Status Language

What each status means.

Available

The feature is accessible through an official AETHER product route, subject to its stated network/provider requirements.

Beta

Accessible for controlled use or testing, but may change and should not be treated as final production behavior.

Development

Being built or integrated. It must not be represented as available merely because source code or UI exists.

Gated

Requires defined prerequisites such as testing, provider readiness, security review, network state or explicit operational approval.

03 / Security Standard

User secrets stay private.

Non-negotiable security rule

AETHER websites, Telegram bot, AI Assistant, support representatives and community administrators should never ask a user to disclose a seed phrase, mnemonic, private key, recovery phrase, password or OTP.

Before signing a blockchain transaction, users should verify the network, destination, asset, amount and transaction intent. Official interfaces do not remove the user's responsibility to review what they authorize.

05 / FAQ

Essential product answers.

Is AETHER one product?

AETHER is the master ecosystem brand. Wallet, ATH Token & Mining, AUTOTRADE and AETHER AI are connected product layers under the same identity.

Does AETHER hold my wallet recovery secret?

The intended self-custody security model keeps recovery secrets with the user. Never provide those secrets to a website, bot, AI assistant or support person.

Does AUTOTRADE guarantee profit?

No. Automated trading involves market, execution, liquidity, slippage and infrastructure risk. Simulation or historical performance is not a guarantee of future results.

How do I know whether a feature is live?

Use the official product interface and its runtime/status indicators. Features marked beta, development or gated should not be treated as generally available.

Where should I verify AETHER links?

Start from this corporate domain, aether.boats, and use the official routes listed above.
