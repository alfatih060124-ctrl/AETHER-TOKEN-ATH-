Direct Referral is ONE unified payout: unranked sponsor receives 10% total; ranked sponsor receives R1 13%, R2 16%, R3 19%, R4 22%, R5 25%, R6 28%, R7 31%, or R8 35% total. These Rank percentages already include the common 10% Direct Referral. Only the incremental Rank portion passes up to a higher Rank, and same Rank receives no uplift, but pass-up continues upward to the next higher Rank. Rank thresholds / weekly salary remain: R1 $1k/$25, R2 $5k/$75, R3 $15k/$200, R4 $50k/$500, R5 $100k/$1k, R6 $250k/$2k, R7 $500k/$5k, R8 $1M/$10k. Qualification requires 5 direct sponsors; small-leg turnover excludes the single largest dynamic leg. Rank Salary remains weekly at 00:30 UTC and lifetime after qualification. Direct Referral / Rank uplift, Lifestyle Bonus / Matching Staking, and Rank Salary use only the protected 50M Marketing / Lifestyle Matching Reserve.

The common Direct Referral is 10%. Rank 1 does not receive 10% + 13%; Rank 1 receives 13% TOTAL, so only +3% is the Rank uplift. Example: Rank 1 direct sponsor receives 13% total; the next eligible Rank 2 receives only +3%, making the cumulative referral path 16%. Pass-up continues only to a higher Rank and skips the same Rank and continues upward until a higher Rank is found. The entire referral path is capped at the Rank 8 total of 35%.
